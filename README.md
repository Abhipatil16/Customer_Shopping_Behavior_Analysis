# Customer_Shopping_Behavior_Analysis

Analyzed customer shopping data using Python (Pandas, NumPy) to clean, transform, and perform 
exploratory data analysis (EDA) on customer demographics and purchase behavior.
•
Used SQL to analyze revenue, customer segments, subscription behavior, discounts, product ratings, 
shipping preferences, and repeat-purchase patterns.
•
Performed customer segmentation based on previous purchase history and created an interactive Power BI 
dashboard to visualize key KPIs, trends, and revenue drivers.
•
Derived business insights from customer behavior and translated findings into recommendations related to 
customer retention, subscription growth, product promotion, and discount strategies.
